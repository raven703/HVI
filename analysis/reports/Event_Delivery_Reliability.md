# Event delivery revision

Implemented: Runtime command journal (16384 records), independent non-destructive cursor, DLL-lifetime monotonically increasing order, connection-local sequence. Atomic cursor/read/snapshot under feed lock. Duplicate held-down commands are retained in journal but suppressed by SDL state transition adapter. Disconnect appends reset before clearing state; reconnect never rewinds cursor. Journal overflow returns explicit lost count and atomic snapshot; adapter discards stale tail and reconciles releases/held keys/buttons. Local queue capacity 16384; overflow recovery discards pending events, counts loss and reconciles snapshot. Loss cannot be reconstructed and is never described as lossless.

SDL Poll/Peep/Wait/WaitTimeout/Pump use one private queue while virtualized. Window/lifecycle events are drained from native queue and preserved; physical input filtered in this process. Peep supports type range, PEEK/GET/ADD, null query. Poll(nullptr) does not consume. Wait polls at 1ms intervals. Main input thread only: general concurrent SDL queue access, event filters/watchers, PushEvent/Flush/HasEvent consistency remain PARTIAL/UNSUPPORTED. Native queue and HVI journal lack a common timestamp ordering; ordering is guaranteed within HVI commands, not between native lifecycle and HVI events.

Relative/absolute coordinates use current SDL window size. Both wheel axes carry integer and precise values. ResetMouse releases buttons and clears coordinates/deltas; Reset also releases keys. F12 virtual/native remains foreground-only. DLL lifecycle supports SDL_Quit then SDL_Init; test repeats twice. Diagnostics exposed as SDL hints HVI_DIAG_LOST/ORDER/SEQUENCE/QUEUE/ERROR; test object's title displays counts and hints. F6 on controller top-level window initiates BOTH 1000 key/click pairs, motion/wheel and disconnect/reconnect; command generation is not itself delivery proof.

Regression event_delivery_reliability validates actual SDL events (1000 KD/KU/MD/MU, duplicate suppression, null Poll, filtered Peep, Wait, absolute coordinates, horizontal/vertical wheel, forced upstream overflow, disconnect and two initialization cycles). Full CTest outcome must be read from build/Testing/Temporary/LastTest.log. This report does not claim an independent pixel oracle, exhaustive queue semantics, second application validation or a complete controller test result viewer.
